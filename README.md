## Покрытие автотестами

В проекте реализованы автоматизированные API-тесты на Go с использованием библиотек `apitest`, `testify` и `gjson`.

### Объявления (Advertisements)

**Позитивные сценарии:**
- Создание объявления со всеми полями: название, описание, цена, количество и фотография.
- Получение созданного объявления по ID.
- Поиск объявления по точному названию.
- Получение фотографий объявления.

**Негативные сценарии:**
- Создание объявления без авторизации — `401 Unauthorized`.
- Создание с недействительным токеном — `401 Unauthorized`.
- Создание с пустым названием — `400 Bad Request`.
- Создание с отрицательной ценой — `400 Bad Request`.
- Создание с отрицательным количеством — `400 Bad Request`.

### Избранное (Favorites)

**Позитивные сценарии:**
- Добавление чужого объявления в избранное.
- Проверка наличия объявления в списке избранного.
- Удаление объявления из избранного.
- Проверка отсутствия объявления после удаления.
- Проверка исчезновения объявления из избранного другого пользователя после удаления объявления владельцем.

**Негативные сценарии:**
- Повторное добавление объявления — `409 Conflict`.
- Добавление собственного объявления — `403 Forbidden`.
- Добавление или удаление несуществующего объявления — `404 Not Found`.
- Получение, добавление и удаление избранного без авторизации — `401 Unauthorized`.

### Организация тестов

В проекте используется разделение на слои:

- `internal/client/http` — формирование и отправка HTTP-запросов.
- `internal/managers` — обработка HTTP-ответов.
- `tests/scenarios` — тестовые сценарии и проверки результатов.
- `tests/testdata` — тестовые данные.

Тесты используют уникальные данные. Для созданных объявлений и записей избранного предусмотрена автоматическая очистка.

Тест удаления объявления из избранного другого пользователя требует два разных тестовых аккаунта.

Тесты выполняют реальные HTTP-запросы к учебному API, поэтому для запуска необходим доступ к серверу TestBoard.

## Запуск тестов

1. Установите любое IDE для разработки: [Jetbrains GoLand](https://www.jetbrains.com/ru-ru/go/) (Платное или по студенческой лицензии), [VS Code](https://code.visualstudio.com/) (бесплатное).
2. Установите [Git](https://git-scm.com/install/) на компьютер
3. [Установите](https://go.dev/doc/install) Go версии 1.25.1
4. [Настройте](https://docs.github.com/ru/authentication/connecting-to-github-with-ssh) доступ к своему Github-аккаунту
   по SSH-ключу.
5. Склонируйте себе репозиторий: `git clone <путь к вашему репозиторию>`
6. Подтяните необходимые зависимости через команду в корне проекта:

```bash
   go mod tidy
```

7. В файле `.env.override` (создайте его в корне, если нет) выставьте правильные значения для переменных окружения:

```
TEST_LOGIN=your_test_login
TEST_PASSWORD=your_test_password

TEST_LOGIN_2=second_test_login
TEST_PASSWORD_2=second_test_password
```

ВАЖНО: .env.override содержит конфиденциальные данные и не должен добавляться в Git.

8. Для запуска всех тестов достаточно выполнить команду в корне проекта:

```bash
  go test ./... -count=1
```

9. Для запуска тестов конкретного раздела:

```bash
  go test -v ./tests/scenarios/advertisement/ -count=1
  go test -v ./tests/scenarios/favorites/ -count=1
```

## Логирование

Для включения логирования request/response в консоль: выставьте переменную окружения `DEBUG=true` в
`.env.override`, для отключения - `DEBUG=false`

```bash
  golangci-lint run
```
